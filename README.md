# AutoFix – Sistema de Gestión de Órdenes de Reparación Automotriz

Plataforma web construida con **ASP.NET Core Web API (.NET 10)**, **ASP.NET Core MVC (.NET 10)**, **Entity Framework Core** y **SQLite**.

## Estructura de la solución

```text
AutoFix.sln
|-- AutoFix.Api/      (Web API: controladores, servicios, EF Core, middlewares)
|-- AutoFix.Mvc/      (MVC: vistas, controladores, HttpClient)
|-- README.md
|-- evidencias/       (capturas y videos de funcionamiento)
```
